<h2>Support</h2>

<p class="section-intro">If you need help with the Terceira Events website or the mobile app, this page tells you what to do.</p>

<div class="venue-card">
  <h3>Reporting a problem with the app</h3>
  <div class="venue-regulars">
    <p>If something does not work as expected — a screen does not load, a notification does not arrive, an event link is broken — please tell us. The fastest way is by email:</p>
    <p><a href="mailto:accounts@chrisrackauckas.com">accounts@chrisrackauckas.com</a></p>
    <p>Please include:</p>
    <ul>
      <li>Your device (e.g. iPhone 15, iPad Pro 13")</li>
      <li>Your operating system version (Settings → General → About → iOS Version)</li>
      <li>The app version (Settings tab inside the app, scrolled to the bottom)</li>
      <li>What you did and what you expected to happen</li>
    </ul>
  </div>
</div>

<div class="venue-card">
  <h3>Suggesting an event</h3>
  <div class="venue-regulars">
    <p>To submit an event for inclusion in the calendar, use the in-app <strong>Suggest Event</strong> screen, or visit our <a href="/suggest/">event submission form</a>. Suggestions are reviewed before being published.</p>
  </div>
</div>

<div class="venue-card">
  <h3>Suggesting an edit to an existing event</h3>
  <div class="venue-regulars">
    <p>Tap the red flag icon next to any event in the app to send us a correction. You can also email <a href="mailto:accounts@chrisrackauckas.com">accounts@chrisrackauckas.com</a> with the event name, the date, and what should be changed.</p>
  </div>
</div>

<div class="venue-card">
  <h3>Privacy questions</h3>
  <div class="venue-regulars">
    <p>See our <a href="/privacy/">privacy policy</a>. The Terceira Events app does not collect personal data. If you still have a question, write to <a href="mailto:accounts@chrisrackauckas.com">accounts@chrisrackauckas.com</a>.</p>
  </div>
</div>

<div class="venue-card">
  <h3>Feature requests and feedback</h3>
  <div class="venue-regulars">
    <p>We are always interested in hearing how the app could be more useful for life on Terceira. Email your ideas to <a href="mailto:accounts@chrisrackauckas.com">accounts@chrisrackauckas.com</a>, message us on <a href="https://www.instagram.com/eventosterceira/">Instagram (@eventosterceira)</a>, or open an issue at <a href="https://github.com/TerceiraEvents/TerceiraEventsApp/issues">github.com/TerceiraEvents/TerceiraEventsApp/issues</a> if you prefer GitHub.</p>
  </div>
</div>

<div class="venue-card">
  <h3>Response time</h3>
  <div class="venue-regulars">
    <p>This is a small community-run project, not a 24/7 service. We aim to reply to support email within a few days. For time-sensitive event corrections (an event tonight that is wrong in the app), the in-app red-flag icon is the fastest path because it pings us directly.</p>
  </div>
</div>
